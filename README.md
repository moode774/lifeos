# LifeOS — مركز قيادة حياتك

نظام شخصي شامل لإدارة الحياة: مهام متكررة مع تذكيرات، جدول يومي بفترات لكل يوم أيامه (دوام / طريق / استرخاء / لعب / رياضة / نوم / عائلة) مع تنبيه عند كل تحوّل، مؤقّت تركيز بومودورو، متتبّع عادات بسلاسل أيام، ملاحظات سريعة "لا تنسَ"، إحصائيات شهرية، بحث، وضع داكن، أصوات، ونسخ احتياطي.

- واجهة عربية RTL بتصميم مستوحى من لوحات التحكم العصرية (كريمي + أسود + أصفر).
- **مزامنة سحابية (Supabase):** أنشئ حساباً من صفحة التخصيص وبياناتك تتزامن تلقائياً بين كل أجهزتك. بدون حساب، تبقى البيانات محلية على جهازك.
- **تطبيق قابل للتثبيت (PWA):** بعد النشر افتح الموقع من جوالك واختر "إضافة إلى الشاشة الرئيسية".
- يعمل على اللابتوب والجوال (تصميم متجاوب بالكامل).

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`

## التقنيات

React 19 · TypeScript · Vite · Tailwind CSS 4 · lucide-react
